# Interfaces web

Prácticas de desarrollo de interfaces con HTML, CSS y JavaScript.

## Archivos principales

- `index.html`: página principal.
- `main.css`: estilos.
- `script.js`: lógica del navegador.
- `images/`: recursos gráficos.
- `SIGN UP & SIGN IN PAGE.html`: práctica de interfaz de acceso.

## Explorar

Abrí `index.html` en el navegador o serví la carpeta con un servidor estático local para revisar la interfaz y sus recursos.
